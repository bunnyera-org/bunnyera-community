\# Community Marketplace



This folder stores BunnyEra Community planning notes for the future community marketplace.



\## Purpose



The Community Marketplace is planned as a space where users and developers can discover and share BunnyEra ecosystem resources.



\## What Can Be Shared



Examples:



\- AI agents

\- Automation workflows

\- Prompt packs

\- Plugins

\- Themes

\- Templates

\- Public tutorials

\- Integration guides

\- Community tools



\## Marketplace Categories



\- Agents

\- Workflows

\- Prompts

\- Plugins

\- Themes

\- Templates

\- Tutorials

\- Developer tools
