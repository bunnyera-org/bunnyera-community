\# AI Agents



This folder stores BunnyEra Community planning notes for AI agent sharing.



\## Purpose



The AI Agents area is planned as a community space where users and developers can share BunnyEra-compatible AI agent definitions, roles, capabilities, and usage examples.



\## What Can Be Shared



Examples:



\- AI CEO agent

\- Product selection agent

\- Listing agent

\- Marketing agent

\- Customer service agent

\- Finance agent

\- Security review agent

\- Repository scanner agent

\- Browser automation agent

\- Workflow runner agent
