\# Community Docs



This folder stores BunnyEra Community public documentation and onboarding guides.



\## Purpose



Community Docs help users and developers understand how to use, join, and contribute to the BunnyEra ecosystem.



\## What Can Be Stored Here



Examples:



\- Community onboarding guide

\- Developer getting started guide

\- FAQ

\- Product introduction

\- Agent sharing guide

\- Workflow sharing guide

\- Prompt sharing guide

\- Plugin publishing guide

\- Theme publishing guide
