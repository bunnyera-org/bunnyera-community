\# Prompts



This folder stores BunnyEra Community planning notes for prompt sharing.



\## Purpose



The Prompts area is planned as a community space where users and developers can share useful BunnyEra-compatible prompt templates.



\## What Can Be Shared



Examples:



\- Ecommerce product description prompts

\- Ad copy prompts

\- Social media prompts

\- Market research prompts

\- Competitor analysis prompts

\- Customer service reply prompts

\- Code review prompts

\- Documentation prompts

\- Security review prompts



\## Recommended Prompt Format



Each prompt should include:



```txt

Prompt Name:

Use Case:

Target User:

Input Required:

Prompt Text:

Expected Output:

Example Result:

Risk Notes:

Prompt Categories
